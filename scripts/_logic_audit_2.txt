CRITICAL FINDINGS REQUIRING IMMEDIATE ACTION
================================================================================

1. WRONG WEBSITE (gdjg_jiangsu, gdgg_jiangsu, dkgs_jiangsu):
   These new spiders target landchina.mnr.gov.cn but their old counterparts
   target www.landjs.com (Jiangsu Land Market). These are COMPLETELY DIFFERENT
   websites with different APIs, different data, and different page structures.
   The new spiders will not collect the Jiangsu data and are effectively broken.

2. STUB IMPLEMENTATIONS (gdjg_jiangsu, gdgg_jiangsu, dkgs_jiangsu):
   These new spiders only scrape the LIST page (title, date, URL) and do NOT
   crawl detail pages at all. All substantive data fields (20+ per spider) are
   hardcoded as empty strings. These are placeholder/stub implementations.

3. md5_value MISMATCH (amac_products, jggg_land):
   md5 construction is DIFFERENT between old and new. This means data that
   should be unique might be treated as duplicate, or vice versa. Critically:
   - amac_products: old=md5(manager_name), new=md5(fund_name+fund_number)
   - jggg_land: old=md5(entry_name+project_location), new=md5(entry_name)
   These will cause different dedup behavior in the new pipeline.

4. API FIELD NAME MISMATCH (amac_securities_product):
   Old uses cpmc/cpbm/gljg/tgjg/barq/slrq/dqr/tzlx/sffj/yzzt keys.
   New uses mpiName/mpiProductCode/aoiName/mpiTrustee/registeredDate/mpiCreateDate.
   If the API returns one format, the other spider will get empty data.
   This needs to be verified against actual API responses.

5. MISSING CONTENT (tax_anhui, all tax spiders likely):
   The new tax spiders do not crawl detail pages, meaning the actual
   announcement body content is NOT collected. Only titles and URLs are stored.
   This is a major data loss.

6. MISSING ATTACHMENTS (tax_anhui):
   Old saves attachment URLs to entity_government_announcement_mapping table.
   New ignores attachments entirely.

7. MISSING PRICE FIELDS (crgg_land):
   guarantee_price, starting_price, price_increase, listing_start_time,
   listing_end_time are all empty in the new spider. These are critical
   fields for land transfer announcements.

8. MISSING CONTACT FIELDS (cjgs_land):
   publicity_period, issuing_authority, contact_unit, unit_address, zip_code,
   contact_phone_number, contacts, email are all empty in the new spider.
